# Курс "Временные ряды и обработка сигналов"
Курс делится на 2 модуля: классические временные ряды и применение нейронных сетей к временным рядам. В данном readme представлены краткие итоги курса по лабораторным работам

## 1 лабораторная. Прогнозирование продаж: анализ и предобработка временного ряда
1. Изучение данных и формирование временного ряда
- Мной был выбран товар JUMBO BAG APPLES с кодом 23199 - это первый товар, с которым было более 1000 взаимодействий. Сам товар представляет из себя авоську с принтом яблок
- Отфильтровал датасет по коду товара, удалил возвраты (чеки, начинающиеся с 'C'). Далее была выполнена агрегация ряда по дням
2. Оценка качества данных
- Пропусков в данных не было обнаружено, нулевые периоды не приравнивались к ошибкам
- Выбросы не удалялись и были сглажены с помощью 99-го перцентиля, что сохранило реальную структуру данных
3. Визуальный и описательный анализ ряда
- Рассчитал ключевые статистики: среднее, стандартное отклонение, коэффициент вариации, асимметрию, эксцесс
- Построил графики скользящих характеристик: мат ожидания и дисперсии от времени
4. Декомпозиция временного ряда
- Применил к ряду классические аддитивные модели, построил acf и pacf
- Выявил волнообразные колебания спроса в течение года и сезонные особенности изменения структуры продаж
5. Стационарность
- Провел расширенный тест Дики-Фуллера и тест KPSS
- Результаты тестов получились согласованными: исходный ряд стационарен, дополнительных преобразований не потребовалось
